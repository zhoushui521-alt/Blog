> 现代技术已经使闲暇在一定限度内不再是少数有闲阶级的特权，而可以成为所有人共享的权利。
> ——Bertrand Russell，《赞闲》（In Praise of Idleness, 1932）

刚下班，想跟大家聊聊最近比较火的 Personal Agent。

它其实就是云端的 Agent。跟手机上的 GPT、桌面端的 Codex、WorkBuddy 这些比，区别在哪？

## 一、Chatbot 是头，Agent 有手

手机上的 GPT，还有网页里只能聊天的那一类，可以统一叫 Chatbot。它像人的头部，能看、能听、能说，就是不能帮你做。它住在手机里，就有手机厂商的种种限制；住在浏览器里，能做的也限于浏览器里，检索、回答、生图、分析。浏览器端的 ChatGPT 想抓你桌面上的一个文件，抓不到，你只能手动上传给它。

Agent 可以理解成人的上半身。它有手，能操作你的电脑。

先把这两个定义分清楚：Chatbot 有大脑，大脑就是 LLM 大模型；Agent 多了一双手。Codex 和 WorkBuddy 正好是「有手」那一边的例子，可以操作你的电脑。

## 二、Personal Agent：住在云端电脑上的 Agent

最近比较火的 Personal Agent，就是住在云端电脑上的 Agent。它解决的问题很直接：人懒得打开电脑，想直接在手机上跟自己的 Personal Agent 对话，让它去云端那台电脑上操作。云端有手，你登录在云端浏览器里的办公软件，它可以直接动。

这套东西在国外可能更好用，很多服务开在 Web 网站上，可以直接操作。国内主要是 ToC 生态，入口收在超级 APP 里，支付宝这类把大量功能集成在一起；网页端没有多少像国外旅游推荐的 TripAdvisor 那样专精一个方向、能在线做定制的东西。

## 三、偷懒是发动机

不是说 Personal Agent 这个概念不好。只是我觉得，其实人每次科技进步，很多东西都是因为懒。这是好事，对大家来说越轻松越好。从最开始的体力劳动，用机器机械的方式替代掉，到现在连脑力劳动也外包出去，让 Agent 帮我们做记忆、做思考。

## 四、端侧 AI 才像未来

我最近对端侧 AI 的方向比较感兴趣。未来人和 AI 的交互方式，更多可能落在端侧上。现在的 Personal Agent 毕竟只是个中间的过渡态，大家还在用手机这些终端；往后可能是一个眼镜、一个耳机，耳钉耳环甚至都算。算力都在云端跑，你身上带的东西只需要做好输入输出，云端做好隐私保密，功能直接在云端分析。本地只管输入输出，负担就小了。

## 五、雷鸟 iO：只做全天智记

前段时间看了雷鸟的 iO 智能眼镜，发现它跟其他眼镜不太一样。其他眼镜做得比较全，视觉拍摄拍照、语音识别、扬声器，能放音乐放通知放回答，功能有点重有点复杂，戴起来可能也有点重。

雷鸟 iO 只做全天智记。它没有扬声器，只有麦克风，加一块显示屏。显示屏很简单，把 AI 回答的内容和通知弹到眼睛前面。吸引我的就是全天智记这个功能：戴着它全天无感，24 小时在记录你。当然不是一直在录音，我觉得它的原理应该是一直在转文字，AI 实时分析，总结成你一天的待办。

这个方向挺好的。但人懒起来，我觉得我甚至不想用一个眼镜。

## 六、从 Vibe Coding 到 Voice Coding，把提示词也放下了

我朋友最近在做 AI 提效的工作，现在大家已经从 Vibe Coding 变成 Voice Coding 了。为什么？我们每个人都买了个大疆的麦克风，口喷式地跟 AI 谈需求。

前段时间在 X 上看到一条推文：我们现在其实没有必要那么专精于 Prompt Engineering。提示词写得好不好，更多是要把自己脑子里的想法流畅地表达出来。

脑子里会有很多思绪。打字，或者想用专业的提示词去写的时候，你会省掉一些觉得不重要的。但实际上，只有你还原完整的现场，AI 才能一步一步引导你，得出你最终想要的答案。你省掉的、觉得不必要的因素，可能都在里面起作用。

人和人聊天总会有纠结，有矛盾，一会儿觉得 A 好，一会儿又觉得 B 也挺好的。跟 AI 讲的时候，就把 ABCD 各种情况都讲给它，再一步步引导。这样就不用分一部分大脑的负载去想「提示词该怎么写它才懂」，重心放在怎么自如地表达出来。

表达之后有两条路。一条是加一步预处理，大模型把你口喷的内容转成文字，再梳理一遍，把矛盾和次要的清洗掉，保留最精华的。另一条是原样转给 AI，直接让它回答。两个方向都可以。

我们最近不想打字，就是觉得没有必要。跟 AI 像聊天一样多轮对话，有什么不确定的，直接让 AI 来问，做决策就好了。

## 七、审美决策是拉开差距的地方

未来感觉人最重要的，是一些审美决策。这才是人和人能拉开差距的点。到时候大家用的模型都差不多，你的判断力、你的审美、你沉淀出来的那种说不清的感觉，会让你自然而然做出符合自己调性的决策。这些决策，就是跟其他人有差异的地方。

## 八、百花齐放，和外包出去的待办

还有个有意思的，OPPO 出了一个录音豆，也是一种端侧 AI 的尝试，也在做全天智记。我觉得以后肯定会百花齐放，智能手表这些也会做端侧的全天智记，都在帮自己分析。

Personal Agent 也是一种尝试。这些 AI 科技往前走，很大原因都是人懒。我自己也一样，把每天要记的重要待办外包给 AI，让它记下来，到时候通知我，其实很好玩。

还有个朋友，他自己也买了个大疆麦克风，他觉得打字太麻烦不如口喷。原先各大厂商不做口喷，是因为识别没那么准：有人有口音，表达又矛盾，语音输入完一波还要修修改改，不如直接手动打字。现在 AI 做了一层中间处理，就好用了。他开始用豆包语音输入法和微信语音输入法，前段时间在用 Typeless，免费额度有点少，又切换到其他产品了。

刚下班那会儿，我只是想聊聊 Personal Agent。聊到现在才发现，从头到尾就一个字，懒。

懒得打字，手就外包给麦克风。懒得记事，待办就外包给 AI。懒得开电脑，云端就长出一双手。回头看，科技每往前走一步，背后差不多都是懒。载体越换越轻，到最后人身上只剩输入输出。

脑子里留下的是什么？大概就是审美了。
